01 CORE THESIS

의료 AI와 전자의무기록(EMR)의 핵심 결함: 맥락과 온톨로지의 단절

현재 임상 현장의 디지털 데이터는 (1) 표현형의 비표준 파편화, (2) 원천 문헌 근거의 분실, (3) 대규모 언어모델(LLM)의 생성 환각(Hallucination)이라는 세 가지 중대한 병목에 직면해 있습니다. 병원마다 같은 혈액 검사나 질환명에 서로 다른 로컬 청구 코드(EDI)를 부여하며, 임상 의사결정 보조 시스템(CDSS)은 권고 사항의 출처가 되는 무작위대조시험(RCT)의 인구군이나 통계적 신뢰구간(CI)을 검증하지 못한 채 텍스트를 생성합니다.

✦ THE TRIPLE DISCONNECT IN CLINICAL INFORMATICS
  • 용어 표류 (Terminology Drift): '당화혈색소', 'HbA1c', 'A1c 정량' 등 다수의 로컬 코드가 단위(NGSP % vs IFCC mmol/mol) 및 측정 장비 차이를 반영하지 못해 환자 코호트 집계 왜곡 유발.
  • 근거 휘발 (Evidence Evaporation): 진료 지침의 요약 문장만 모델에 주입될 경우, 해당 권고가 '특정 바이오마커 양성군'에만 국한되는지 여부를 알 수 없어 금기(Contraindication) 처방 위험 발생.
  • 밀집 벡터 검색(Dense Vector RAG)의 구조적 한계: 코사인 유사도 기반 임베딩 검색은 4-hop 이상의 복합적 다제 병용 요법(Cytochrome P450 약물 상호작용)이나 시간적 선후 관계를 추론할 수 없음.

IYN 아키텍처는 이를 해결하기 위해 단순한 텍스트 임베딩 대신, 시맨틱 지식 그래프(Semantic Knowledge Graph)와 W3C RDF/OWL 명세, HL7 FHIR R4 표준을 결합한 결정론적(Deterministic) 추론 레이어를 구축합니다.

04 RETRIEVAL ARCHITECTURE

임상 의사결정을 위한 결정론적 GraphRAG 아키텍처

순수 벡터 검색(Vector RAG)은 어휘적 유사성에 의존하므로, "신장 기능 저하(eGFR < 30) 환자에게 메트포르민 투여가 금기되는 생리학적 경로"와 같은 인과 관계를 추적할 수 없습니다. IYN GraphRAG 엔진은 RDF 지식 트리플과 온톨로지 계층을 활용하여 정확한 제약 조건을 사전에 검증합니다.

SPARQL 1.1 :: CONTRAINDICATION GRAPH QUERY DETERMINISTIC // 2.1ms 
PREFIX iyn: <https://iyn.one/schema#>
PREFIX snomed: <http://snomed.info/id/>
PREFIX rxnorm: <http://purl.bioontology.org/ontology/REST/>

SELECT ?drugName ?contraindicationType ?evidenceDoi WHERE {
  # 특정 환자의 활성 진단 및 신기능 상태
  ?patient a iyn:PatientProfile ;
           iyn:hasCondition snomed:431855005 ; # CKD Stage 4
           iyn:latestEgfr ?egfr .
  FILTER (?egfr < 30.0)

  # 투약 후보 약제의 금기 온톨로지 탐색
  ?drug a iyn:PharmaceuticalAgent ;
        iyn:hasRxNorm ?drugId ;
        rdfs:label ?drugName ;
        iyn:contraindicatedIn ?condition .
  
  # 원천 가이드라인 및 RCT 증거 링크 확인
  ?contraindication iyn:involves ?drug ;
                    iyn:targetCondition ?condition ;
                    iyn:severity "FATAL_RISK" ;
                    iyn:supportedBy ?evidence .
  ?evidence iyn:doi ?evidenceDoi .
}
